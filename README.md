# Driveline Finance

A car loan repayment calculator: purchase details, lender fees, balloon/residual structuring, a target-repayment solver, an amortisation schedule with a chart, and saved quotes with filtering.

Live at [driveline-finance.vercel.app](https://driveline-finance.vercel.app).

## Stack

Vite + React + TypeScript + Tailwind CSS v4. No backend — saved quotes persist in the browser's `localStorage`.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Pushes to `main` deploy automatically via the connected Vercel project.
